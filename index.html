WUMETAX TableCraft｜免費線上 HTML 表格製作器與 WordPress RWD 表格轉換工作站

WUMETAX TableCraft 是專為內容創作者、網站管理員、行銷人員與前端開發者設計的線上表格製作工具。無需撰寫任何 HTML 或 CSS，即可將 Excel 試算表與 CSV 資料轉換為具備完整無障礙語意（thead、tbody、scope）、獨立 CSS 命名空間，且完美支援手機版 RWD 響應式顯示的網頁表格程式碼。

如何將 Excel 轉成 HTML 表格？

  1. 在 Excel 或 Google 試算表選取您的資料範圍並複製（Ctrl+C）。
  2. 點擊上方工具列的「匯入 Excel / CSV」，將資料貼入文字框並確認解析預覽。
  3. 在左側工作區設定金額（NT$）、百分比、網址或推薦方案強調欄位。
  4. 於右側面板選擇喜歡的視覺範本與手機版 RWD 模式，即可一鍵複製 HTML/CSS。

如何貼進 WordPress Gutenberg 編輯器？

  1. 在中央下方的程式碼產生器選擇「1. WordPress Gutenberg 相容版」。
  2. 點擊「一鍵複製完整程式碼」。
  3. 前往 WordPress 文章或頁面編輯器，新增一個「自訂 HTML（Custom HTML）」區塊並貼上。
  4. 若您的網站安全性設定會過濾 <style> 標籤，可改用「純 HTML + 行內樣式」模式，或將 CSS 貼至外觀自訂的「額外 CSS」中。

三種手機版 RWD 表格呈現模式

  • 水平滑動表格：保持桌面版完整對照結構，僅在表格容器內提供平滑觸控橫向捲動，絕不造成整頁破版。
  • 手機獨立卡片式：在手機螢幕自動將每一列轉為直向資訊卡片，自動標註欄位名稱，適合規格表與聯絡名冊。
  • 重點欄位展開模式：小螢幕先顯示核心欄位，次要欄位自動收納於點擊展開面板中，兼顧畫面簡潔與資料完整性。

常見問題 FAQ 與隱私安全聲明

Q1：我匯入的公司報價或客戶資料會被上傳到伺服器嗎？

絕對不會。WUMETAX TableCraft 採用 100% 瀏覽器本機運算（Client-side Processing），所有 CSV 解析、編輯與儲存皆在您的裝置記憶體與本機 LocalStorage 中完成，不傳送任何資料至外部 API 或雲端伺服器。

Q2：產生的表格 CSS 會影響我原本網站佈景主題的樣式嗎？

不會。每張表格都會自動綁定專屬的命名空間識別碼（例如 .wmt-tc-a1b2c3），絕不使用全域 table {} 或 td {} 選擇器，同一頁面放置多張不同風格的 TableCraft 表格也不會互相干擾。

Q3：這項工具需要付費、註冊會員或安裝 WordPress 外掛嗎？

完全免費、無使用次數限制、無需註冊登入，產生的表格程式碼乾淨獨立，不需要在 WordPress 安裝任何笨重的表格外掛，也不會強制加入任何浮水印或廣告連結。
